## 高阶考题及评分（拟定 100 分）

不重复按钮保持、基础梯形图等入门内容。提交物统一为：需求假设和 I/O 契约、ST/厂商工程、诊断与最小补丁、正常/异常轨迹、FAT JSON、未覆盖边界和回滚。评分看可重跑的行为，不按代码长度或讲解流畅程度给分。

- **Q1 跨工位转运（25 分，今晚可执行）**：20ms 扫描、两个工位和双命令执行器；请求/ACK 携带单调序号。背压期间不启动；同一序号只启动一次；错误 ACK 不完成；STOP 排空当前件并禁止后续进料；失鲜同一扫描将命令置零。已故障事务须人工核对物料，复位不重发旧序号。I/O/时序说明 5、状态与事务 5、正常/背压 5、去重/异常/恢复 10。反馈入口为 Lab 04 的 15 个场景。
- **Q2 复合故障诊断（25 分）**：给一份能编译却存在错误 ACK 接受、禁用超时或持续 Reset 的程序，以及含通信失鲜和位置矛盾的轨迹。提交首因、可证伪的假设、最小 ST 修复及反例回归。首因/假设 5、日志定位 5、补丁 5、负控制及重放 5、隔离恢复/回滚 5。今晚验证的是测试能检出 5 种缺陷，未运行独立模型修复实验。
- **Q3 双轴同步（20 分，未执行）**：给定主从轴、2ms 任务、机械限位、速度/加速度/单位和允许跟随误差；须定义回零、Enable/Busy/Done/Error、轴失能和中途暂停策略。将绝对编码器重启与非回零轴混用作为反例。契约 5、参数预算 5、故障联锁 5、真实虚拟轴/台架误差与时序证据 5。Linux 离散位置模型不为此题得分。
- **Q4 协议/HMI（15 分，未执行协议栈）**：给 Modbus 地址表、32 位字序和 OPC UA 数据质量要求；注入半包、超时、旧 ACK、重连后持续 START，要求通信诊断、幂等命令和安全恢复。映射/字序 5、断线/失鲜/去重 5、协议抓包与离线验证 5。逻辑失鲜布尔量只能证明控制分支，不能代替报文测试。
- **Q5 配方一致性（10 分，部分可执行）**：版本 V1 在在制品中途切换 V2，V2 含越界或单位错误；要求原件保持 V1 快照，新件原子使用合法新版本，拒绝忙态提交，并说明掉电后的持久化策略。参数/单位 3、快照 2、版本 2、原子提交/追溯 3。今晚覆盖范围、版本边沿、忙态拒绝和快照；持久化与单位转换未实现。
- **Q6 FAT/发布（5 分）**：每项需求绑定断言和原始失败证据；在干净的已提交基线上复现，注明工具哈希和现场缺口。追踪 2、重跑/哈希 2、边界/回滚 1。

拟定整体门槛：≥80/100，且 Q3≥12、Q4≥9，并通过全部安全/事务否决项。不得用本 Lab 全通过代替整体通过，不推导薪资或雇主录用资格。

**一票否决**：相反执行器命令同时为真；故障/失鲜后仍输出动作命令；恢复安全回路或持续 Reset 导致自行运行；旧请求/错误 ACK 导致重复或虚假完成；删除安全/超时检查以骗过测试；缺失失败证据却声称通过；未经授权对生产 PLC 下载/启动/Force/写 I/O；把仿真结论写成现场安全验证。

## 工具选择、已验证与不能覆盖

使用 [官方 STruC++ 0.6.0 发布](https://github.com/Autonomy-Logic/STruCpp/releases/tag/v0.6.0)，固定官方 Node 资产 SHA-256 和 npm 锁文件，复用 bauhinia 的 Node/GCC/Python；详见 [Lab 04](../../labs/04-senior-benchmark/README.md)。官方 [CLI](https://github.com/Autonomy-Logic/STruCpp/blob/v0.6.0/docs/CLI.md) 支持 ST→C++。这是一种独立原生测试 Runtime，**不等同于 TIA Portal/PLCSIM、CODESYS 工程/SoftPLC、TwinCAT 或 Windows 工业套件**。没有安装商业软件、申请试用、下载未知来源安装包或改系统服务。

已验证：源码编译、扫描契约、有限的离散物理反馈、15 场景、哈希一致重放、5 缺陷反证、编译诊断和 NDJSON 请求/响应。未验证：任何模型达到上述能力标准；完整招聘 JD；实际 Modbus/OPC UA、PLC 调度抖动、掉电/RETAIN、序号回绕、异步多 PLC、伺服动力学或厂商工程可导入性。急停测试仅证明采样输入后的软件命令变零，不证明真实停机时间、STO、PL/SIL、接触器反馈或现场风险控制。

后续顺序：先补完整可核实 JD 和一个独立 Agent 修复实验；再补协议报文测试；最后在获得对应环境/许可与授权后接厂商虚拟控制器和隔离台架。现场 SAT、安全回路与风险评估由合格人员在实际设备执行，仿真不替代。
