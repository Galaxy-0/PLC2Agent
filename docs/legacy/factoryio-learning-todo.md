# PLC 虚拟产线全流程体验 TODO

## 项目目标

完成一个“箱体自动分拣站”小型工业自动化项目，体验从工艺需求、I/O 设计、PLC 编程到 Factory I/O 仿真、故障测试和验收交付的完整流程。

首轮技术路线：

```text
Factory I/O（虚拟工厂）
        ↕ Modbus TCP
OpenPLC（控制逻辑）
        ↕
HMI / 监控界面
```

AutoShop 稳定运行后，再尝试把程序迁移至汇川 H5U；如果以后有实体 PLC，再进行真实下载和 I/O 调试。

## 一、工艺需求

- [ ] 按下启动按钮后，输送线进入自动运行。
- [ ] 箱子到达检测区后识别箱体类型。
- [ ] A 类箱沿主输送线直行。
- [ ] B 类箱到达推料位置后，由气缸推入侧面输送线。
- [ ] 推料完成后，气缸自动缩回。
- [ ] 同一时间只处理一个箱子，避免碰撞。
- [ ] 分别记录 A 类、B 类和总产量。
- [ ] 按停止按钮后停止进料，当前箱体处理完成后停机。
- [ ] 按急停按钮后，所有危险动作立即停止。
- [ ] 解除急停后不得自动恢复，必须人工复位并重新启动。

## 二、故障需求

- [ ] 箱子进入后，限定时间内未到达下一传感器，触发“输送超时”。
- [ ] 气缸伸出后，限定时间内未收到伸出到位信号，触发“推料器伸出故障”。
- [ ] 气缸缩回后，限定时间内未收到缩回到位信号，触发“推料器缩回故障”。
- [ ] 出口持续被遮挡时，触发“出口堵塞”。
- [ ] 发生故障后停止进料，并锁存故障。
- [ ] 传感器恢复时不得自动消除故障。
- [ ] 只有排除故障原因并按下复位，才允许清除故障。

## 四、顺序控制设计

| 步骤 | 状态 | 主要动作 | 转移条件 |
|---:|---|---|---|
| 0 | 待机 | 全部停止 | 启动且系统正常 |
| 10 | 等待来料 | 启动输送带 | 入口检测到箱子 |
| 20 | 类型检测 | 保存 A/B 类型 | 类型确认完成 |
| 30 | 输送到分拣位 | 主输送带运行 | 到达推料位置 |
| 40 | A 类放行 | 主线继续运行 | A 出口检测到箱子 |
| 50 | B 类推料 | 停止主线，气缸伸出 | 气缸伸出到位 |
| 60 | B 类送出 | 侧线运行 | B 出口检测到箱子 |
| 70 | 气缸复位 | 气缸缩回 | 气缸缩回到位 |
| 80 | 完成 | 对应产量加一 | 返回等待来料 |
| 900 | 故障 | 停止危险动作 | 排障并复位 |

程序建议拆分：

```text
PRG_Main
├── FB_ModeControl       自动、停止、急停、复位
├── FB_Sequence          分拣状态机
├── FB_Cylinder          气缸动作和超时
├── FB_Alarm             报警检测与锁存
└── FB_ProductionCount   产量计数
```

### 阶段 5：正常流程调试

- [ ] 验证待机状态。
- [ ] 验证启动和停止。
- [ ] 一次投入一个 A 类箱，验证直行和计数。
- [ ] 一次投入一个 B 类箱，验证推料、送出、复位和计数。
- [ ] 连续投入多个箱子。
- [ ] 验证不会发生碰撞、漏分或重复计数。
- [ ] 验证正常停止会等待当前箱体处理完成。

### 阶段 6：异常和安全调试

- [ ] 移除运输中的箱子，验证输送超时。
- [ ] 模拟气缸无法伸出到位。
- [ ] 模拟气缸无法缩回到位。
- [ ] 持续遮挡出口，验证堵塞报警。
- [ ] 运行中按下急停，检查危险输出是否立即关闭。
- [ ] 解除急停，确认设备不会自动重启。
- [ ] 在故障原因仍存在时按复位，确认故障不能清除。
- [ ] 排除原因后复位并重新启动。

## 六、FAT 验收清单

| 编号 | 测试条件 | 预期结果 | 状态 |
|---|---|---|---|
| FAT-01 | 系统正常时按启动 | 输送线进入等待来料状态 | [ ] |
| FAT-02 | 投入 A 类箱 | 从 A 出口离开，A 计数加一 | [ ] |
| FAT-03 | 投入 B 类箱 | 推入 B 出口，B 计数加一 | [ ] |
| FAT-04 | 运输中移除箱体 | 触发输送超时并停止进料 | [ ] |
| FAT-05 | 气缸无法伸出到位 | 到时报警，流程禁止继续 | [ ] |
| FAT-06 | 气缸无法缩回到位 | 到时报警，流程禁止继续 | [ ] |
| FAT-07 | 出口持续遮挡 | 触发出口堵塞报警 | [ ] |
| FAT-08 | 运行中急停 | 危险输出立即关闭 | [ ] |
| FAT-09 | 解除急停 | 系统不自动启动 | [ ] |
| FAT-10 | 故障未排除时复位 | 报警不能被清除 | [ ] |
| FAT-11 | 按正常停止 | 当前箱完成后停机 | [ ] |
| FAT-12 | 连续运行多个箱体 | 无碰撞、漏分和重复计数 | [ ] |
