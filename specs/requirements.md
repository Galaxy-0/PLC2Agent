# 箱体自动分拣站需求

## 工艺需求

| ID | 需求 | 验证方式 |
|---|---|---|
| REQ-001 | 系统正常且处于待机时，启动请求使系统进入自动模式 | 场景 |
| REQ-002 | A 类箱沿主输送线进入 A 出口 | 场景 |
| REQ-003 | B 类箱在推料位停稳后被推入侧线 | 场景 |
| REQ-004 | 每个成功离开的箱子只计数一次 | 场景 + 不变量 |
| REQ-005 | 正常停止应完成当前箱体后停止进料 | 场景 |

## 安全需求

| ID | 需求 | 验证方式 |
|---|---|---|
| SAF-001 | 急停回路断开后40ms内关闭运动输出 | 时序属性 |
| SAF-002 | 推料气缸伸出时主输送带不得运行 | 不变量 |
| SAF-003 | 解除急停后不得自动恢复运行 | 场景 |
| SAF-004 | 上电和通信中断时运动输出采用安全默认值 | 静态检查 + 场景 |

## 故障需求

| ID | 需求 | 验证方式 |
|---|---|---|
| FLT-001 | 箱体在限定时间内未到达下一传感器时锁存输送超时 | 故障场景 |
| FLT-002 | 气缸未在限定时间内伸出或缩回时锁存执行器故障 | 故障场景 |
| FLT-003 | 出口持续遮挡时锁存堵塞报警 | 故障场景 |
| FLT-004 | 故障原因未消除时复位不得清除报警 | 故障场景 |

## 待明确参数

- A/B 类型识别机制；
- 箱体最小间距；
- 正常停止的最大等待时间；
- 运输、伸出、缩回和出口堵塞超时；
- 手动模式下允许的点动动作；
- 计数保持策略。
