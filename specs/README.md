# 首个工程规范：箱体自动分拣站

`specs/` 当前保存箱体分拣站的目标契约草案，用于指导自动化单元级 Plant 和后续
Agent 验收实验。它还不是已实现的通用 IR，也不是当前 `labs/` Runtime 的隐式配置。

当前事实来源按范围区分：

- 单个可运行实验：该 Lab 的 ST、I/O 映射、测试和 Trace；
- 未来分拣单元目标：本目录的需求、I/O、控制、Plant 和场景草案；
- 通用跨 Runtime/Plant 语义层：等待真实 Adapter 需求稳定后再提炼。

第一版草案暂时拆成少量易审查文件：

| 文件 | 内容 |
|---|---|
| `requirements.md` | 工艺、安全、故障和验收需求 |
| `io.yaml` | 信号、PLC 地址、Plant 端口和 Modbus 映射 |
| `control.yaml` | 模式、状态机、不变量和报警 |
| `plant.yaml` | 被控对象组件与物料模型 |
| `scenarios/*.yaml` | 正常、异常和安全测试场景 |

约束：

- 不在生成的 ST 中手工维护业务真相；
- 不在 Web UI 中保存隐藏配置；
- 每个需求必须至少映射一个场景或静态属性；
- 每个物理输出必须声明安全默认值；
- 所有时间量必须带单位。
